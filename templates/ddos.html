Common DDoS Attack Vectors & Signatures

DDoS-Guard's AI model is benchmarked against 15 distinct network traffic profiles, covering volumetric reflection, state exhaustion, and application flooding.

1 / 15
Reflection UDP : 53

DrDoS_DNS

DNS-based Distributed Reflection DDoS. Attackers exploit open recursive DNS resolvers with spoofed source IPs to flood target servers with amplified responses.

Reflection UDP : 389

DrDoS_LDAP

LDAP-based Distributed Reflection DDoS. Abuses exposed Lightweight Directory Access Protocol daemons to generate disproportionate response payloads.

Reflection UDP : 1434

DrDoS_MSSQL

Microsoft SQL Server resolution reflection. Sends MC-SSTP discovery probes to SQL Server Browser services, reflecting large response flows.

Reflection UDP : 123

DrDoS_NTP

Network Time Protocol amplification. Exploits legacy NTP "monlist" commands to achieve up to 556x traffic amplification against the victim.

Reflection UDP : 137

DrDoS_NetBIOS

NetBIOS Name Service reflection. Abuses exposed NBNS services on Windows machines to reflect voluminous name status queries.

Reflection UDP : 161

DrDoS_SNMP

Simple Network Management Protocol reflection. Sends GetBulk requests with public community strings to flood the target via network hardware.

Reflection UDP : 1900

DrDoS_SSDP

Simple Service Discovery Protocol amplification. Leverages exposed UPnP IoT devices to reflect continuous M-SEARCH discovery responses.

Reflection UDP : Variable

DrDoS_UDP

General UDP reflection attack. Employs miscellaneous connectionless UDP endpoints to saturate inbound network pipeline bandwidth.

Direct Flood TCP/UDP : 389

LDAP Flood

Direct volumetric LDAP flood. Generates overwhelming rates of directory queries, exhausting server CPU, worker threads, and memory.

Direct Flood TCP : 1433

MSSQL Flood

Direct database connection flood. Saturates SQL query listener threads with malformed or incomplete connection handshakes.

Direct Flood TCP/UDP : 139

NetBIOS Flood

Direct NetBIOS session service flooding. Targets file-sharing and domain services on Windows servers to cause denial of service.

Protocol Exploit UDP : 111

Portmap / RPC

Open Network Computing Remote Procedure Call (ONC RPC) flood. Exploits rpcbind daemon tables to cause resource starvation.

State Exhaustion TCP : Variable

SYN Flood

Classic TCP state-table exhaustion. Sends thousands of TCP SYN packets with spoofed IPs, filling the backlog queue with half-open connections.

Protocol Exploit UDP : 69

TFTP Flood

Trivial File Transfer Protocol flood. Exploits UDP-based file requests to tie up bandwidth and transfer sockets on vulnerable systems.

Volumetric UDP : Random

UDP Flood

Raw Layer 4 volumetric flood. Sends high-velocity random UDP datagrams to force servers into repeatedly issuing ICMP "Destination Unreachable" replies.

Defensive Architecture

DDoS Prevention & Defense-In-Depth

Essential operational practices and multi-layered controls to safeguard enterprise infrastructure against coordinated attacks.

Continuous Traffic Inspection

Deploy continuous flow telemetry to monitor ingress packet rates, TCP flag ratios, and anomalous packet burst signatures before disruption occurs.

Intelligent Rate Limiting & Firewalls

Implement adaptive SYN cookies, connection velocity limits, and upstream BGP Flowspec filtering to drop malicious traffic at perimeter routers.

AI-Powered Anomaly Detection

Leverage machine learning classifiers to distinguish legitimate traffic spikes from distributed multi-vector attacks with high precision.

Anycast Cloud Scrubbing

Distribute traffic globally via Anycast routing, redirecting volumetric floods to high-capacity cloud scrubbing centers for packet sanitization.

Endpoint & Service Hardening

Close open recursive resolvers, disable NTP monlist, block vulnerable NetBIOS/RPC ports (111, 137, 1434), and keep network stacks patched.
